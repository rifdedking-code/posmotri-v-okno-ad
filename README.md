# Посмотри в окно

Адаптивность не входит в задачу: проект повторяет фиксированный макет сервиса для поиска коротких видео городов в разное время суток.

## О проекте

Страница загружает видео по городу и времени суток, показывает карточки роликов и позволяет переключать видео кликом по карточке. Поиск и подгрузка карточек реализованы в JavaScript.

## Запуск

Откройте файл `index.html` в современном браузере. Для корректной работы запросов к API рекомендуется запускать проект через локальный веб-сервер.

## Структура

- `index.html` — разметка приложения и шаблоны карточек;
- `styles/style.css` — стили интерфейса;
- `styles/preloader.css` — стили индикаторов загрузки;
- `styles/error.css` — стили сообщения об ошибке;
- `scripts/script.js` — логика поиска и работы с видео;
- `fonts/` — шрифты проекта.
